# AppStorm — мобильное приложение

Многоэкранное приложение на React Native и Expo. Интерфейс авторизации повторяет основные экраны Figma; после входа доступны городская лента, чаты и профиль.

## Открыть в VS Code

1. Откройте папку `AppStorm` через **File → Open Folder**.
2. В терминале папки выполните `npm install`, если зависимости ещё не установлены.
3. Запустите приложение командой `npx expo start`. Для Android Emulator нажмите `a` в терминале Expo.

Если Node.js в вашей сети не доверяет системным сертификатам, в текущем окне PowerShell можно задать `$env:NODE_OPTIONS = '--use-system-ca'`. Если PowerShell блокирует `npx.ps1`, используйте `npx.cmd`.

## Открыть в Android Studio

В проекте уже есть папка `android/`. Откройте именно её через **File → Open** в Android Studio. Для запуска из терминала с установленными Android SDK и эмулятором используйте `npm run open:android`.

Чтобы пересоздать native-папку из Expo-конфигурации, выполните `npm run prebuild:android`. Команда обновляет содержимое `android/`.

## Структура

```text
AppStorm/
├── App.tsx
├── android/                   # Android Studio / Gradle project
├── src/
│   ├── components/            # Общие кнопки, поля и экран авторизации
│   ├── navigation/            # Stack + нижняя навигация
│   ├── screens/
│   │   ├── auth/              # Вход, регистрация, SMS-код, город, пароль
│   │   └── main/              # Лента, список чатов, переписка, профиль
│   ├── theme/                 # Цвета приложения
│   └── types/                 # Типы маршрутов
├── app.json
└── package.json
```

## Экраны

**По макету Figma:** вход, восстановление пароля, подтверждение номера, сброс пароля, регистрация и выбор города.

**Дополнительно к макету:** городская лента, список чатов, экран переписки и профиль — четыре новые страницы.

Формы и переходы работают локально в приложении. Для реальной регистрации, доставки SMS, аккаунтов и синхронизации сообщений потребуется подключить сервер/API.
